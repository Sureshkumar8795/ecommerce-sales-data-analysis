# Dataset provenance and definitions

`raw_data.csv` is a deterministic **synthetic** dataset generated by `scripts/generate_data.py` using seed `20261117`. It contains no real customer names, purchases, or transactions. Customer names are randomly assembled fictional names. The raw file intentionally includes a small number of missing fields, inconsistent category casing, invalid dates, and duplicate rows so the cleaning workflow can be demonstrated.

Each row represents one product line within an order. An order can contain multiple rows and customer IDs recur across orders. Dates span 2023-01-01 through 2025-12-31.

- `Total Sales` is line gross value after discount: `Quantity * Unit Price * (1 - Discount)`.
- `Profit` is estimated line contribution after an assumed category-specific product cost. Margins are modeling assumptions in `scripts/generate_data.py`, not observed company costs.
- Revenue and profit analyses include `Delivered` lines only. Processing, returned, and cancelled rows are retained for status analysis but excluded from delivered-sales KPIs; refunds are not modeled.
- Outlier detection flags the 1.5 x IQR upper fence for total sales and does not remove legitimate high-value orders.

Do not present these records or model assumptions as actual company or customer data.
